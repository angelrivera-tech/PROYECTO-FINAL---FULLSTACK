# Manual de usuario — Worldnews

## Requisitos
Para usar Worldnews necesitas:

- **Dispositivo:** computadora, tableta o teléfono. El diseño se adapta a cualquier tamaño de pantalla.
- **Navegador web actualizado:** Google Chrome, Microsoft Edge, Mozilla Firefox o Safari (versiones recientes), con JavaScript activado.
- **Conexión a Internet:** la aplicación está publicada en línea en https://proyecto-final-worldnews.netlify.app y no requiere instalar nada.
- **Correo electrónico válido y accesible:** es necesario para crear una cuenta, recibir el código de verificación (2FA) al iniciar sesión y recuperar o cambiar los datos de la cuenta.
- **Almacenamiento local del navegador habilitado:** la sesión se guarda en el navegador. Si borras los datos del sitio o usas una ventana privada, tendrás que iniciar sesión de nuevo.
- **Para leer noticias** no hace falta una cuenta. **Para publicar, editar o eliminar artículos, guardar noticias y cambiar tu perfil** debes iniciar sesión.
- **Imágenes (opcional):** para subir fotos de perfil o imágenes de artículos se aceptan JPG, PNG, WEBP o GIF (y AVIF en los artículos). Tamaño máximo: 2 MB para la foto de perfil y 5 MB para las imágenes de artículos.

## 1. Página de inicio
Al entrar al sitio verás las últimas noticias. Haz clic en cualquier noticia para leerla completa. El menú lateral da acceso a todas las secciones.

## 2. Crear una cuenta (Sign In)
1. Abre **Sign In** desde el menú.
2. Completa nombre de usuario, correo y contraseña.
3. Confirma el registro; después podrás iniciar sesión.

## 3. Iniciar sesión (Log In)
1. Abre **Log In** e introduce tu usuario y contraseña.
2. Recibirás un **código de verificación** en tu correo.
3. Escribe el código para completar el inicio de sesión. El código expira a los 5 minutos.
4. La sesión dura 7 días. Si expira, la aplicación te avisa y te lleva de nuevo a **Log In**.

## 4. Guardar noticias
- Usa el botón de guardar (pin) en una noticia para leerla más tarde.
- Consulta tus noticias guardadas en **Saved News**.

## 5. Perfil (Profile Settings)
Desde **Profile Settings** puedes ver la información de tu cuenta, cambiar tu foto de perfil y solicitar cambios de contraseña o correo (se confirman por email).

## 6. Recuperar la cuenta
Si olvidaste tu contraseña o usuario, usa el enlace **¿Olvidaste tu contraseña o usuario?** en la página de Log In. Recibirás un correo con instrucciones.

## 7. Donaciones y contacto
- **Subscriptions / Donations** permite apoyar el proyecto.
- **Contact Us** y **About Us** contienen información del equipo.

## 8. Panel de administración
Solo las cuentas administradoras ven el botón **Admin Panel** en el menú. Desde ahí se pueden gestionar usuarios y artículos, y en **Manage Articles** crear o editar noticias con el editor.
